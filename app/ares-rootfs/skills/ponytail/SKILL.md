# Ponytail — Token 优化 Skill

## 目标
降低 Agent 每次交互的 token 消耗，让输出更精简、改动更小、复用更多。

## 规则（默认注入到 Agent 系统提示）
1. **最小修改**：只改与任务直接相关的代码，不顺手重构、不清理无关代码。
2. **复用已有能力**：优先调用项目内已有的工具/函数/组件，不新造轮子。
3. **减少代码输出**：能用一句话说明改法的，不要粘贴整段重复代码；diff 而非全文。
4. **避免过度设计**：不为假想需求加抽象、加参数、加配置项。三行重复优于一个提前抽象。
5. **简洁回复**：回答直奔结论，去除填充语、客套、重复用户原话。
6. **批处理**：合并多个小改动为一次提交/一次输出，减少往返。

## 适用工具
Claude Code / Cursor / Codex / OpenCode / HOS Agent。

## 说明
本 Skill 为纯提示层优化，不引入额外运行时依赖，安装后默认生效。
