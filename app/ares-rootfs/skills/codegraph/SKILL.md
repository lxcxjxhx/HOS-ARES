# CodeGraph — 代码语义图谱 Skill

## 用途
把"反复读文件找符号"改为"一次查图拿结构"，减少大仓库审计的 token 消耗。

## 推荐流程
1. 需要理解某个符号（函数/类/导入/调用链）时，优先查询语义图谱，而非整文件读取。
2. 获取符号定义与调用关系后，只读取与任务直接相关的少数文件片段。
3. 复用已构建的持久化代码记忆，避免重复索引同一仓库。

## 集成方式（MCP）
- MCP 工具：42 个结构化代码理解工具（函数、类、导入、调用链）。
- 支持语言：38 种。
- 持久化：内存层缓存已索引代码，跨会话复用。

## 依赖
- 需在 rootfs 内安装 CodeGraph 服务端 / MCP 并联网索引目标仓库。
- 未安装时回退为逐文件读取（本 Skill 仅做引导，不阻断执行）。
