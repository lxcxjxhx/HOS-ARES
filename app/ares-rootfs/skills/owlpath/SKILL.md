# OwlPath — 代码知识压缩 Skill

## 用途
以结构化知识表示压缩上下文，减少 Agent 在 Bug 修复与检索时所需 token。

## 推荐流程
1. 将仓库知识组织为结构化表示（符号、依赖、数据流、语义摘要），而非原始全文。
2. Bug 修复时先检索与缺陷相关的压缩知识，再读取定位到的少量源码。
3. 复用已压缩的知识索引，避免重复处理同一区域。

## 适用场景
- 大型仓库 Bug 修复
- 跨文件检索
- 多轮 Agent 会话的上下文保持

## 说明
OwlPath 为知识压缩/流程层方案；未内置实现时，Agent 遵循"先结构化、后读取"的检索策略以降低 token。
