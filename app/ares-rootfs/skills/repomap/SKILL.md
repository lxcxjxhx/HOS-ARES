# Aider RepoMap — 上下文压缩 Skill

## 用途
把"读整个仓库"压缩为"读地图 + 高价值片段"，显著降低 token 消耗。

## 推荐流程
1. 首先生成仓库结构地图：目录树 + 关键 symbol（函数/类）及其所在文件。
2. 依据地图判断任务相关的少数文件，仅读取这些文件的高价值片段。
3. 更新文件后刷新地图，保证后续任务基于最新结构。

## 关键点
- 地图是树 + symbol 索引，而非文件全文。
- 只检索与任务关键词相关的符号，跳过无关文件。
- 大仓库分析时收益最明显。

## 说明
Repomap 为提示/流程层优化，不引入额外运行时依赖；未内置工具时按上述流程手工人为控制读取范围。
