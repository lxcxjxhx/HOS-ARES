# sqli-waf-bypass

WAF 拦截 `UNION SELECT` 时，先确认拦截发生在哪一层（边缘 / 应用 / 参数解析）。

常见绕过方向（按"改动最小"排序）：

1. 注释切开关键字：`UN/**/ION SE/**/LECT`。
2. 大小写与空白变体：`UnIoN%09SeLeCt`、行内换行 `%0a`。
3. 参数污染：同名参数重复提交，观察后端取首值还是末值。
4. 编码层：双重 URL 编码、Unicode 全角、`char()` 拼接。

**纪律**：以上任一手法都必须伴随 control 组。没有 control 的"通了"不算结论，
只能记为线索（lead），交回强制验证。
