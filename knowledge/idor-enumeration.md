# idor-enumeration

越权读取的判定核心是**双账号对照**，不是"改了个 id 就出来了数据"。

步骤：

1. 账号 A 建一个只属于它的对象，记下引用形式（纯数字 / UUID / 复合键）。
2. 账号 A 自己读一次，确认基线是 200。
3. 改用账号 B 的会话读同一引用。
4. 判定：B 拿到 200 **且内容与 A 读到的一致** → 越权成立；B 拿到 403/404 → 不成立。

**纪律**：
- 只改引用不改会话，得到的是"对象可预测"，不是越权；
- 只改会话不改引用，得到的是"会话失效"，也不是越权；
- 两者必须同时替换，缺一个就只能记线索。
