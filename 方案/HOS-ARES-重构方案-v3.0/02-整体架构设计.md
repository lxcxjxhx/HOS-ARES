## 2.2 各层职责

| 层级 | 名称 | 核心职责 | 关键组件 |
|------|------|---------|---------|
| L1 | Android UI 层 | 用户交互、任务输入、结果展示、付费门控 | Jetpack Compose |
| L2 | AresGateway 网关层 | 意图识别、任务路由、DeepSeek-Reasonix 调用封装 | SkillRegistry.kt |
| L3 | **Agent 编排层** | **统一 Agent 框架**——缓存优化、MCP 集成、子 Agent 调度 | **DeepSeek-Reasonix** |
| L4 | MCP 服务层 | 安全工具能力暴露（MCP 2026-07-28 无状态协议） | mobile-security-mcp 等 |
| L5 | 容器运行时层 | Linux 环境隔离、Node.js 运行时 | Termux + proot-distro |

## 2.3 数据流向

```
用户输入
  → L1 Compose UI（对话 / Skill 市场 / 任务卡片）
  → L2 AresGateway：Intent Classifier + SkillRegistry 路由
  → L3 DeepSeek-Reasonix：cache-first loop 编排
  → L4 MCP Server：调用安全工具（静态分析 / 动态插桩 / RASP 绕过 …）
  → L5 Termux + proot-distro 容器执行
  → 结果经 L3 → L2 流式回传 → L1 任务卡片实时展示
```
