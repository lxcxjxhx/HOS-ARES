# 05 · 实施路线图（以 DeepSeek-Reasonix 为核心）

## 总体时间线

| Phase | 名称 | 周期 | 里程碑 |
|-------|------|------|--------|
| Phase 1 | 基础环境搭建 | 1 周 | `reasonix ask "hello"` 可运行 |
| Phase 2 | MCP 工具链集成 | 1-2 周 | `/mcp` 能看到已连接服务器 |
| Phase 3 | AresGateway 开发 | 1-2 周 | 任务卡片状态机完整流转 |
| Phase 4 | Android UI 开发 | 2-3 周 | 对话主界面 + 付费管理 |
| Phase 5 | 打包与测试 | 1-2 周 | APK 端到端通过安全测试场景 |

**合计：约 6-10 周**

## Phase 1：基础环境搭建（1 周）

1. 集成 Termux + proot-distro（Alpine 3.20）
2. 安装 Node.js 22+（DeepSeek-Reasonix 运行环境）
3. 通过 `npm i -g reasonix` 安装 DeepSeek-Reasonix
4. 配置 DeepSeek API Key，验证 `reasonix ask "hello"` 可运行

**验收标准**：在 Termux 容器内 `reasonix ask "hello" --model deepseek-v4-flash` 成功返回并流式输出。

## Phase 2：MCP 工具链集成（1-2 周）

1. 在容器中安装 `mobile-security-mcp`（pip install）
2. 安装 `mcp-termux` v7.0
3. 配置 `~/.reasonix/config.json` 注册 MCP Server
4. 验证 DeepSeek-Reasonix 可通过 `/mcp` 看到已连接的服务器

**验收标准**：`/mcp` 输出包含 mobile-security、mcp-termux、jadx-headless 等服务器及其工具列表。

## Phase 3：AresGateway 开发（1-2 周）

1. 实现 SkillRegistry（关键词匹配 + 意图理解）
2. 封装 DeepSeek-Reasonix CLI 调用（stdin/stdout 流式通信）
3. 实现任务卡片状态管理（PENDING → RUNNING → DONE/FAILED）

**验收标准**：输入任务 → 正确路由到对应 Skill → 任务卡片状态机完整流转。

## Phase 4：Android UI 开发（2-3 周）

1. Jetpack Compose 对话式主界面
2. 任务卡片实时流式展示
3. 设置页面（API Key、模型选择、付费管理）
4. Google Play Billing 集成

**验收标准**：真机可完成「对话输入 → 流式结果展示 → 任务卡片归档」全流程。

## Phase 5：打包与测试（1-2 周）

1. APK 打包（含 Termux + proot-distro + DeepSeek-Reasonix + MCP Server）
2. 端到端测试（SAST、SCA、渗透测试等场景）
3. 性能优化（首次启动速度、内存占用）

**验收标准**：APK 安装后开箱即用，完成一个完整的安全审计任务（如 APK 静态分析）且内存占用可控。
