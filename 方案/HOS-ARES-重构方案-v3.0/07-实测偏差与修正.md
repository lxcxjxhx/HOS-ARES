## 7.3 修正后的集成架构（AresGateway 视角）

```
Android App (L1 Compose)
  ↓ HTTP(S) + SSE（token 鉴权）
AresGateway (L2 Kotlin)
  ↓ 本机 loopback（Termux 容器内）
reasonix serve --addr 127.0.0.1:PORT --auth token   ← 首选（长会话、前缀缓存友好）
  ├── 任务任务卡片 ← run --events-jsonl（结构化事件：PENDING→RUNNING→DONE/FAILED）
  ├── 简单问答   ← -p --output-format stream-json
  └── 代码/安全审查 ← review
      ↓ MCP ([[plugins]] / reasonix mcp add)
L4 MCP Servers（mobile-security-mcp / mcp-termux / jadx-headless-mcp / droid-mcp …）
      ↓
L5 Termux / proot-distro (Alpine) 容器
```
