# 06 · 新旧方案对比与总结

## 6.1 关键差异对比

| 维度 | 原方案（废弃稿） | 新方案 v3.0（DeepSeek-Reasonix 为核心） |
|------|----------------|----------------------------------------|
| **Agent 框架** | 自研 Python import 软路由 | **DeepSeek-Reasonix**（完整 Agent 框架） |
| **Agent 循环** | 自研 ThreadPoolExecutor | **Cache-first loop**，99.82% 缓存命中率 |
| **MCP 集成** | 自研 NDJSON Bridge | **内置 MCP 客户端**，stdio + Streamable HTTP |
| **插件系统** | 无 | **插件驱动**，MCP Server 贡献工具/提示词/资源 |
| **子 Agent** | 无 | **Planner + 子 Agent** 支持可信 MCP |
| **权限管理** | 无 | **deny > ask > allow** 三级权限门控 |
| **自定义命令** | 无 | **自定义斜杠命令**支持 |
| **容器层** | 自研 proot 包装 | Termux + proot-distro |
| **安全工具** | 自研/手动集成 | mobile-security-mcp 等成熟 MCP Server |
| **开发工作量** | 需重写 Agent 框架 | **零 Agent 框架开发**，仅需集成配置 |

## 6.2 总结

以 **DeepSeek-Reasonix** 为统一 Agent 框架的核心优势：

1. **零 Agent 框架开发**：DeepSeek-Reasonix 已提供完整的 Agent 循环、MCP 客户端、插件系统、子 Agent、权限管理
2. **DeepSeek 原生优化**：99.82% 缓存命中率，API 成本降低约 80%
3. **MCP 开箱即用**：内置 MCP 客户端，支持 stdio + Streamable HTTP
4. **Android 完美兼容**：WASM 替代原生模块，Termux 上功能完全一致
5. **生态成熟**：32.9k GitHub Stars，活跃社区

**HOS-ARES 的开发重点从“重写 Agent 框架”转变为“集成 DeepSeek-Reasonix + 配置 MCP Server + 开发 Android UI”，大幅降低开发成本与维护复杂度。**

## 6.3 一句话结论

> 新的 HOS-ARES 不再是一个 Agent 框架工程项目，而是一个 **Agent 框架集成 + 安全 MCP 工具链配置 + Android 体验工程** 项目——把成熟框架和工具链直接装进 APK。
