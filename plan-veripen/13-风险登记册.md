## 2. 七个翻车点速查（贴在显示器上）

```
0 假数据        → 禁 mock；只用真实靶场/公开快照/受管拟真集，`lint-nodata-stub` 挡
0' 硬路由       → 零地址；`lint-noroute` 挡；写不出就走 BLOCKED，不许兜底
1 范围失控      → 范围在 16 冻结；新需求进 99，不许插队进当前批次
2 靶场不稳      → 官方镜像 + 契约可达探测 + 就绪再跑
3 Windows 装不上 → 全容器，宿主零依赖
4 模型超时      → 预跑 + 录屏 + demo-offline
5 没证据        → capsule 缺失不写报告（渲染期抛错）
6 现场卡住      → 离线演示开关一条命令
```

## 3. 停止条件（什么情况下必须停下来）

| 现象 | 必须做 |
|---|---|
| 出现任何一次 scope 越界 | 停线，复盘四处校验，补测试，重跑全量 |
| `judge` 三轮不一致 | 停线，找隐藏 IO/时钟/随机 |
| 同一 oracle 在靶场正样本上 DP 反复抖动 | 降级为 INCONCLUSIVE，先把稳定性做好再判 VERIFIED |
| 报告里出现措辞违规 | 修 lint，不放行 |
| 交付前 `doctor` 有任何红项 | 不交付 |
| **`lint-noroute` 有任何命中** | **停线修代码；不许加白、不许"下批一起改"** |
| **`routeset_sha256` 三轮不一致** | **停线查 resolver 的非确定性** |
| **某步的渲染结果无法由 routeset 推出** | **停线，定位那次提交并整段回退（这是 hardroute 复活的唯一可靠信号）** |
| **`SKIPPED(route_unresolved)` > 0** | **停线修发现源，不许调低门槛让它"看起来通过"** |
