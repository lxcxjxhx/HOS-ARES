# 17 · 权威链与证据门

> 本册（`plan-veripen/`）是**规划权威**，不是执行权威。执行权威在真正的项目目录里。
> 本文定义：三者各管什么、当前处于哪一档状态、下一道门是什么、证据怎么分类。
>
> **v3 新增一节 §0**：本册的**设计不变量**。它是"改任何一篇都不能碰"的底线，
> 优先级高于本文其余部分与其余 27 篇。

## 0. 设计不变量（改文档之前先读这一节）

| # | 不变量 | 出处 | 为什么不可动 |
|---|---|---|---|
| I1 | 判定是纯函数（无 IO / 时钟 / 随机） | `01 §3.1` | 可复现、可离线、可单测全挂在这上面 |
| I2 | 三条件合取才出 VERIFIED（probe ∧ baseline ∧ control） | `07 §0.2`（框架级 `three_way_holds` 兜底） | FP=0 的唯一实现方式 |
| I3 | 客户差异只进 profile；core 零客户串 | `01 §1` / `02` | "能卖第二家"的机械判据 |
| I4 | 模型不参与判定，也不指定地址 | `08 §7` | 前一句管可信度，后一句管**不腐化** |
| I5 | scope 四处校验 + fail-closed | `05 §1` | "敢用"的全部依据 |
| I6 | **地址只能由 `route_discovery` 产出** | `27 §2` N1–N2 | 唯一能阻止 hardroute 复活的机制 |
| I7 | **重试 = 重发现；找不到面 = BLOCKED** | `27 §4` N4 | 禁止"兜底路径"这条退路 |
| I8 | 证据内容寻址 + 只增不改 | `06 §1` | 审计与 replay 的前提 |
| I9 | 数据真实性：禁 mock / 禁假后端 | `26` | bench 数字有效性的前提 |

**这九条里，I6/I7 是 v3 新增的**，也是最容易被"为了赶进度"牺牲的两条。
所以它们有最强形式的机械保证：类型系统（N1/N2）+ CI（N3）+ bench 运行时校验（N6）。

**改文档的规则**：任何改动如果削弱 I1–I9 中任一条，必须先在本文 §0 记录"为什么必须削弱"，
再由 driver 明确批准。**没有这一条记录，改回去。**

## 1. 权威三层（不许互相抄成三份大文档）

| 层 | 文件（项目建设后路径） | 回答什么 | 本册对应 |
|---|---|---|---|
| 总设计案 | `<project>/总设计案.md` | 做什么、为什么、不做什么、四态决策 | `00-总规划` + `16-完整范围与交付地图` |
| 蓝图 | `<project>/蓝图集/BLUEPRINT_INDEX.md` + 领域蓝图 | 按什么边界做到什么证据 | `21`（18 批）+ `14`（能力边界扩张） |
| 续接指针 | `<project>/NEXT.md` | 现在从哪继续、最近证据、下一道门 | 本册未持有（项目建后才存在） |

**本册的内部问题**：29 篇 + 5 份 schema 同时承担"总设计案 + 蓝图 + 规格"三种职责。
项目建设后必须**分流**，否则规划越写越厚、执行越读越乱。

所以它同时出现在"总设计案（不变量）"和"领域蓝图（BP-ROUTE）"两处，这不重复：
前者是原则，后者是交付物。

## 2. 蓝图档位（本项目该选哪一档）

| 档位 | 条件 | 本项目 |
|---|---|---|
| `single-blueprint` | 单主循环、少量组件 | ❌ 不够：18 批里有 5 个独立验收门 |
| **`blueprint-set`** | 多领域但仍是一个产品，存在独立交付物与验收门 | ✅ **选这个**：深度 2，直属领域蓝图 ≤6 |
| `program-blueprint-set` | 多宿主、多阶段、长期迁移 | ❌ 过度：本项目单宿主、单一产品 |

**定档结果**：`blueprint-set`，`maxDepth=2`，`maxChildren=6`，`runtimePersistentBlueprintBudget=0`。
六个领域蓝图：`BP-CORE`（内核/调度/guard）、`BP-PROFILE`（客户档）、`BP-EVIDENCE`（证据/replay）、
`BP-CAPABILITY`（14 类 oracle + 契约解析）、**`BP-ROUTE`（路由解析层）**、`BP-DELIVERY`（报告/离线包/控制台）。

**渐进提取**：初始化只建索引，**不预建 6 个空壳**；做到对应波次时再提取，ID 分配后不得重排改义。
`BP-ROUTE` 在 B1.5 完成时提取（它是唯一一个必须在 W1 内提取的）。
