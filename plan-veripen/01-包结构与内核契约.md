# 01 · 包结构与内核契约

> 本文是**架构冻结文档**。所有后续实现以此为准，改动走 `13-风险登记册.md` 的变更记录。
>
> **v3 变更**：新增 `veripen_core/routes/`（路由解析层，规格见 `27-无硬路由架构.md`）。

## 1. 四包分层与依赖方向

```
            ┌────────────────────────────────────────────────────┐
            │                     veripen_cli                    │  run/replay/bench/doctor/package/report/routes
            └───────┬──────────────────────┬─────────────────────┘
                    │                      │
            ┌───────▼────────┐    ┌────────▼─────────┐
            │ veripen_oracles│───▶│  veripen_core    │
            │ 14 个验证器插件 │    │ 调度/agent/guard │
            │ (只见 RouteBinding)│  │ routes/证据/接口 │
            └────────────────┘    └────────┬─────────┘
                    ▲                      │ 读
                    │                      │
            ┌───────┴──────────────────────▼─────────┐
            │   profiles/<name>/*.yaml  (纯数据)      │
            │   + config/bindings/*.yaml (路由绑定)   │
            └────────────────────────────────────────┘
```

**依赖铁律**

1. `core` 不 import `oracles`，只依赖抽象 `Oracle` 协议（依赖倒置）。
2. `core` 与 `oracles` 都**不得**出现客户标识（域名、公司名、车型、接口路径）。`make lint-noleak` + `make lint-noroute` 强制。
3. `profiles` 是纯数据，不允许包含可执行代码，**不允许包含任何可网络定位字面量**（`27` N3）。
4. 唯一出口是 `cli`，库层不 `print`、不读环境外状态。
5. **`routes` 是唯一能产出 `RouteBinding` 的地方**；`tools.http` 只接受 `RouteBinding`（`27` N1/N2）。

## 3. 内核接口契约（签名冻结）

### 3.1 Oracle 协议（v3：只见绑定，不见地址）

```python
class ImpactClass(str, Enum):
    READ_ONLY = "read_only"
    REVERSIBLE_WRITE = "reversible_write"   # 本期不启用

class Verdict(str, Enum):
    VERIFIED = "VERIFIED"
    REFUTED = "REFUTED"
    INCONCLUSIVE = "INCONCLUSIVE"
    BLOCKED = "BLOCKED"

@dataclass(frozen=True)
class RouteCall:
    """oracle 想发的一次请求：说的是"对哪个已解析的绑定、改哪些参数、用谁的身份"。"""
    ref: RouteRef                          # 不透明身份，不含路径
    params: dict[str, str]                 # 参数值（payload 归 oracle 管）
    role: str                              # auth provider id
    method_override: str | None = None     # 极少数需要换动词（如探 OPTIONS）
    # 注意：没有 url / path / host / port 字段 —— 类型上写不出来

@dataclass(frozen=True)
class RequestPair:
    variant: str                 # 变体名描述符，如 "bool_true"/"bool_false"/"control"
    baseline: HttpTrace          # 基线请求的完整可复现记录（含 route 块）
    probe: HttpTrace             # 变体请求的完整可复现记录

class Oracle(Protocol):
    id: str                      # "sqli_bool_diff"
    version: str                 # "1.0.0"，进 capsule
    cwe: str                     # "CWE-89"
    impact: ImpactClass
    requires: list[str]          # 例 ["auth:secondary"]，不满足则 BLOCKED
    params_schema: type[BaseModel]
    selector_tags: list[str]     # 例 ["object_read"]，用于向 routes 要候选（不含地址）

    def applicable(self, ctx: TargetContext) -> bool: ...
    # 入参是 binding 不是 url；出参是 RouteCall 不是报文
    def plan(self, ctx: TargetContext, base: RouteBinding) -> list[RouteCall]: ...
    # 关键：judge 是纯函数，无 IO、无时钟、无随机
    def judge(self, pairs: list[RequestPair]) -> Judgement: ...

@dataclass(frozen=True)
class Judgement:
    verdict: Verdict
    reason: str                  # 机器可读码 + 人读短句
    assertion: dict              # {"kind":"differential","expected":...,"observed":...}
    confidence: float            # 0..1，规则算出，不让模型给
    route_strength: str          # 判定所依赖的绑定最低置信档（observed/contract/crawl）
```

**两条设计共同构成技术核心**：

> ① **判定是纯函数，网络是外围。** → 可 100% 单测、离线回放、三次跑分一致、模型不确定性挡在判定外。
> ② **地址是运行时解析结果，不是代码常量。** → 目标改版/换环境不需要改代码，也不可能写死路径。

`route_strength` 是 v3 新增：判定必须自己声明"我依赖的绑定有多可信"。
用 `crawl`/`probe` 级绑定得出的结论，报告里自动降级表述（见 `09 §3.1`）。

### 3.1.1 工具定义的三条硬要求（借用 `29 零件 G` 的壳，改掉两个缺陷）

样本里有一个 `ToolRegistry`（`register / registerAll / callTool + stats`），
`stats{calls, failures, avgDuration}` 的形状好用；但**两个缺陷必须改**：

| 缺陷 | 样本行为 | 我们的要求 |
|---|---|---|
| 无风险等级 | 工具定义只有 `name/description/handler` | **`impact: read_only \| reversible_write` 必填**，缺失即启动失败 |
| 同名静默覆盖 | `console.warn` 后覆盖 | **抛错**，不许覆盖（否则后注册的能替掉特权工具） |

```python
@dataclass(frozen=True)
class ToolDef:
    name: str
    description: str
    impact: ImpactClass          # ★ 必填，无默认值
    requires: tuple[str, ...]    # 例 ("auth:secondary",) 不满足则 BLOCKED
    params_schema: type[BaseModel]
    # 注意：没有 url / handler->fetch 这类直接出网的能力；出网只能走 tools.http(binding)

def register(tool: ToolDef) -> None:
    if tool.name in _REGISTRY:
        raise DuplicateTool(tool.name)      # ★ 不许静默覆盖
    _REGISTRY[tool.name] = tool
```

**为什么 `impact` 必须无默认值**：有默认值就一定有人不填；不填就会走默认（宽松）分支。
这与 `02 §1` 的"任何布尔型安全开关默认都是不许可"是同一条原则。

**为什么"不许覆盖"重要**：注册顺序在插件化后会变得不可控。允许覆盖 =
"某个第三方插件可以把 `request_approval` 的实现换掉"。这是供应链级的洞。

### 3.2 三个可变点，其余全冻结

| 可变点 | 扩展方式 | 是否改内核 |
|---|---|---|
| 客户差异 | 新增 `profiles/<name>/` | ❌ |
| 漏洞类别 | 新增 `veripen_oracles/<id>/` 并注册 | ❌ |
| 报告规范 | `report.frameworks[]` + 模板片段 | ❌ |
| **发现源** | 新增 `routes/sources/<name>.py` 并注册 | ❌ |

除此之外任何"想加个 if"的冲动，进二期池。

### 3.3 TargetContext（传给 oracle 的唯一上下文）

```python
@dataclass(frozen=True)
class TargetContext:
    asset: AssetRef              # 不透明句柄（id/kind/criticality/tags）；value 不在这里暴露
    bindings: RouteSet           # 本次可用绑定集（内容寻址、只读）
    selectors: dict[str, Selector]  # profile 里的语义选择器
    auth: dict[str, AuthHandle]  # role -> 句柄（不暴露明文，取用时解密）
    params: BaseModel            # oracle 自己的参数（来自 profile）
    clock_t0: int                # 统一时钟（UTC 秒）
    oob: OobChannel | None       # 本地回调通道（ssrf 用）
    resolver: ResolverHandle     # 只能调 resolve(query)，不能读内部状态
```

**为什么 `base_url` 没了**：v2 的 `base_url: str` 是硬路由的合法入口——
有了它，任何 oracle 都能用 `base_url` 拼出任意子路径。删掉这个字段，等于拆掉那个入口。

## 4. 模块职责表（谁做什么，谁不许做什么）

| 模块 | 做 | **不做** |
|---|---|---|
| `scheduler` | 扫描过期租约、重排、判死信 | 不执行任务、不发请求 |
| `lease` | 领/续/释放，全部 Redis 原子操作 | 不管业务状态 |
| `routes.resolver` | 按 `RouteQuery` 产出 `RouteSet`；唯一能构造 `RouteBinding` | **不猜路径**、不在无候选时给默认值、不读 profile 里的地址（那里没有） |
| `routes.sources.*` | 从各自来源取候选并标注 provenance/confidence | 不合并、不排序、不写缓存（那是 merge/cache 的事） |
| `routes.merge` | structural_key 去重、provenance 合并、稳定排序 | 不做网络 IO |
| `guard.scope` | **四处**校验，失败即抛 `ScopeDenied` | 不重试、不降级、不"尽力而为" |
| `guard.ratelimit` | 令牌桶排队，记录等待时长 | 不静默丢弃 |
| `tools.http` | 发请求、归一化响应、4KB 截断、错误分类 | 不做判定、不猜语义、**不接受 str 地址** |
| `oracles.*` | 产出 `RouteCall`、纯函数判定、产出 assertion | 不发请求、不构造报文、**不持有地址** |
| `evidence` | 组 capsule、算哈希、脱敏、seal、写 `route` 块 | 不改判定结果 |
| `report` | 三视图渲染 | 不引入报告里没有的证据 |
| `agent` | 决定"下一步调哪个 oracle/工具/是否重发现" | **不参与判定**、**不指定地址** |

最后两行是纪律：agent 拿不到写 finding 的权力，也拿不到指定地址的权力。
它能做的只有：选 oracle、选 selector、选参数、触发 `rediscovery`、收尾。

## 5. 关键数据流（一次任务的完整链路）

```
1  POST /tasks {profile, asset_ids, oracle_ids}
     └─ idem_key = sha256(engagement|asset|oracle|params_canonical)
        └─ 冲突 → 直接返回已有 task_id（不重复打目标）
2  worker 心跳续租 → 原子领取 QUEUED 任务 → LEASED → RUNNING
3  guard.plan：scope/deny/enabled/impact 四查（不通过 → BLOCKED finding）
4  ★ route_discovery（每资产每任务一次，结果缓存进 RouteSet）
     RouteQuery{asset, selectors, auth, budget}
       → sources(contract/observed/crawl/probe/operator)
       → merge（structural_key 去重 + 稳定排序）
       → RouteSet{routeset_sha256, bindings[]}
       └─ 空结果 → 全部依赖它的 oracle 标 BLOCKED(route_unresolved)，不发包
5  agent 循环：
     选 oracle（按 selector_tags 与 RouteSet 覆盖）→ guard.binding（绑定已解析）→ guard.preflight
       → 令牌桶 → tools.http.send(binding, params) 发基线
       → oracle.plan(ctx, binding) → RouteCall[] → tools.http 发变体 + 对照
       → oracle.judge（纯函数）→ evidence.seal(capsule 含 route 块) → record_finding
6  失败分流（27 §4）：
     ROUTE_STALE/DRIFT → resolve_routes(reason=STALE|DRIFT) → 新绑定再试（计 max_rediscovery）
     网络抖动/429/5xx → 退避重试**同一绑定**
7  guard.post_connect：每次连接后按解析 IP 复核，越界即断连 + 记事件
8  预算耗尽或收敛 → DONE；证据缺失的 finding 降级为 UNVERIFIABLE 不入报告
9  report 渲染 MD/SARIF/JSON，每条带 capsule ref + routeset_sha256 前 12 位
```

**第 4 步是 v3 新增的**，也是整条链路的"地址诞生点"。
它之前的所有环节都拿不到地址，它之后的所有环节都只拿引用。

## 6. 缓存与幂等边界

| 对象 | 幂等键 | 说明 |
|---|---|---|
| task | `sha256(engagement|asset|oracle|params_canonical)` | 唯一索引，重复提交返回同一结果 |
| **RouteSet** | `routeset_sha256`（规范化 JSON） | 内容寻址；同查询同结果（`27 §3.6/§3.7`） |
| **RouteBinding** | `sha256(routeset_sha256|ref)` | 绑定本身不可变；过期靠 TTL，不靠重算 |
| oracle run | `sha256(task_id|oracle_id|oracle_version|asset_id|routeset_sha256)` | **routeset 变更即视为不同 run** |
| capsule | `self_sha256`（规范化 JSON） | 内容寻址，二次生成字节相同 |
| 报告渲染 | `sha256(sorted(finding_ids)|template_ver)` | 同输入同输出 |
