# 15 · 开工提示词（批次版 · 复制即用）

> **用法**：项目目录建好后，按 `21` 的批次顺序，一次只粘**一个批次卡**给 agent。
> 每批结束看 DoD 输出，绿了再进下一批。
>
> 为什么不一次性粘全量：写代码快，**验证和集成慢**。一次跑 18 批 = 产出一个无法定位失败的大文件。
>
> **v3 加一条**：所有模板的硬约束里都有 **"零地址"** 那三行。
> 这三行不是提醒，是 `lint-noroute` + 类型系统 + 契约测试三重强制的摘要。
> 如果 agent 违反，DoD 命令会直接红。

## §C · 全量总纲提示词（只用于评审，不做开工用）

```
做一个可审计、可复现、可离线部署的渗透验证内核，代号 veripen。

【架构】四包 + profiles + cli + web(只读)
veripen_core      调度/agent/guard/routes/证据/Oracle协议    ← 零客户串、零地址
veripen_oracles   14 类验证器（A 6 / B 5 / C 3，见 18），只见 RouteBinding
veripen_contract  机器可读契约 → RouteSet（见 19），不发网络请求
veripen_cli       run/replay/bench/doctor/package-offline/report/cases/routes/stats/lint-*
profiles/<name>/  demo-a（SaaS）· demo-b（车云），零地址、零明文凭据
checks/           认证半自动检查单（OAuth2/mTLS/Session/SAML，见 20）

【核心设计（不许改）】
1 判定纯函数：judge(pairs) 无 IO/时钟/随机
2 三条件合取：probe ∧ baseline ∧ control，无 control 不出洞
3 模型只影响"跑不跑得到"，不影响"判定是什么"；无模型（scripted planner）也能跑完（A8）
4 客户差异只进 profile；core diff = 0 是能卖第二家的机械判据
5 scope 四处校验 + fail-closed；越界一次整轮作废
6 ★ 地址只能来自 route_discovery；代码/配置/提示词/报告零地址（A9）
7 ★ 重试=重发现；找不到面 = BLOCKED，永不兜底

【枚举与常量（写死）】
Verdict: VERIFIED | REFUTED | INCONCLUSIVE | BLOCKED
Task: QUEUED | LEASED | RUNNING | AWAITING_APPROVAL | DONE | FAILED | DEAD_LETTER | CANCELLED
Finding: CANDIDATE | VERIFIED | REFUTED | UNVERIFIABLE | BLOCKED
Impact: read_only | reversible_write
Replay: OK | PARTIAL | FAILED | BLOCKED | ROUTE_UNRESOLVED | ROUTE_DRIFT | NEVER
路由来源: contract | observed | crawl | probe | operator
置信档: 1.00 observed / 0.95 operator / 0.90 contract / 0.70 crawl / 0.50 probe / 0.30 inferred(仅排序)
心跳 5s / TTL 30s / 扫描 5s / max_attempts 3 / 退避 1s,4s,16s(±20%)
绑定 TTL 900s / min_confidence 0.70 / max_rediscovery 3 / 重发现冷却 2s,4s,8s
QPS 20 burst 40 / 每资产并发 2 / 排队上限 5s / 输出截断 4KB
预算 steps 120 / tokens 400k / wall 1800s / cost 5USD；80% 收敛
idem_key = sha256(engagement|asset|oracle|params_canonical)
capsule_id = 自身 sha256；profile_hash 与 routeset_sha256 进每条 capsule

【数据表】tasks / routesets / route_bindings / task_events / findings / capsules / approvals / bench_runs（见 03）
【报告】MD/SARIF/JSON 同源；ruleId=veripen/<oracle>/<CWE>；双指纹（finding + route）
【评测】44 例（28 正 16 负）× 3 轮；FP=0；越界=0；routeset 三轮一致；人工基线并列展示
【边界】不做：时间盲注 / 白盒 SARIF in-out / 交互式工具 / 多模态车机 / SAML 全自动 / 多租户 K8s
【执行】按 21 的 18 批，一批一验收，禁止一次跑多批；B1.5 先于 B2
```

## 给 agent 的五条纪律（每次粘提示词都带上）

1. **只读本批相关文档**，不通读 28 篇；不确定时读 `16 §3` 能力表定位文档。
2. **DoD 输出必须贴原文**，不许"应该可以"；失败就开一条临时支线（一层、绑父批次、关闭后回归）。
3. **越界即停**：改到"允许路径"以外、需要新依赖、需要放宽断言——立刻停下来说明原因。
4. **★ 写不出地址就停下**：如果你发现"必须知道某个路径才能继续"，那不是要你写死的信号，
   而是要你回到 `27` 看哪个抽象缺了。**在代码里写一个默认路径，是最贵的错误。**
5. **★ 不许加白**：`config/noroute.allowlist` 只能在"确实是误报"时加，且每行带理由、总数 ≤6。
   为了让 lint 通过而加白，等于删掉这道闸门。
