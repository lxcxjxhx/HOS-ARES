# H29 · 交付说明（v1.0 现状）

> 这份文档只回答一个问题：**现在这套东西能做什么、怎么验、还缺什么。**
> 不写规划（那是 H07），不写规格（那是 H02–H05），不重复账本（那是 `.veripen/batches.jsonl`）。

---

## 1. 一句话

**给一个目标，不管它有没有 OpenAPI，跑出一条可复核的链路：面从哪来 → 判了什么 → 凭什么信 → 哪块没测。**

---

## 2. 三条入口

| 命令 | 需要契约 | 面的来源 | 置信 | 用途 |
|---|---|---|---|---|
| `veripen run --openapi spec.json` | 要 | 契约声明 | 0.90（contract） | 有契约的标准跑法，出报告 |
| `veripen run --discover` | **不要** | 观测推断 | 0.70（crawl） | 没契约时先攒面再跑 |
| `veripen hunt` | `--openapi` 或 `--discover` 二选一 | 同上 | 同上 | 边跑边打印，看得见每一步 |
| `veripen discover` | 不要 | 观测推断 | 0.70 | **只看不判**：这次能看见哪些面 |
| `veripen chat` / `veripen agent` | — | — | — | 自然语言驱动上面几条 |
| `veripen console` | — | — | — | 只读控制台，十页 |

共同命令的发现参数只在 `veripen_cli/_discover_args.py` 定义一次：

```
--discover-rounds / --discover-pages     （discover 上还有 --max-rounds/--max-pages 别名）
--render          渲染 HTML，补 JS 生成的入口与同源 XHR
--submit-forms    提交无副作用的 GET 表单（探针值 1）
```

## 3. 面从哪来（发现）

| 来源 | 批次 | 能拿到什么 | 局限 |
|---|---|---|---|
| 首页链接 / 表单 | B86·B94 | `<a>`、`<form>` 的 method 与字段名 | 只读源码 |
| robots.txt / sitemap.xml | B107 | 站点自己发布的目录 | 对方不发布就没有（sias 是 404） |
| 浏览器渲染 | B106 | JS 生成的链接、同源 XHR | 慢（~1s/页）、依赖浏览器通道 |
| GET 表单提交 | B112 | 结果页里的入口 | 只 GET；POST/点击刻意不做 |

**参数名三处都不丢**：路径段（`{p1}`）、查询串（`?q=`）、表单字段（`name=q`）——
这是 B103 / B108 两次踩坑换来的（前两次都在记录层被重建掉了）。

标签由**响应形状**推断，不看路径词：`object_read / object_list / param_injectable /
file_read / content_write`，并标 `tag_sources=structural`（推断，不是声明）。

## 4. 判定与证据

- 每条 oracle 是纯函数：`applicable → plan → judge`；判定必须**三条件**成立，
  并带 control（三向对照）。
- 结论四态：`reported / undetermined / error / not_run`。**`not_run` 与 `error` 不许写成"未发现"**。
- `coverage.json`：六类缺口（面没 oracle、oracle 没跑、刻意排除、阻塞/未判定/错误、低置信面、claim 无观测），
  `completion_status` 只有 "converged + finished" 才算完成。
- 报告抬头写**面的来源**（B109）：`discover（crawl，置信 0.70；预算 N 轮 / M 页）—— 面由观测推断，不是契约声明`。
- 控制台十页只读，写操作一律 405；能直接打开 `run` 的 `findings.json`（B100）。

## 6. 残留缺口（按"能不能补"排序）

| # | 缺口 | 现状 | 补的前提 |
|---|---|---|---|
| 1 | **E1 真隔离** | 只有 Job Object 资源隔离（Windows），无命名空间 | 需要容器运行时；本机没有，永远未验 |
| 2 | **DOM XSS 判定** | 能渲染、能取渲染后 DOM，**判定侧没有 oracle** | 需要给 oracle 一条浏览器执行通道（架构级） |
| 3 | **POST / 点击** | 刻意不做 | 一次 POST 可能就在生产写数据；要做需授权模型 |
| 4 | **sitemapindex 递归** | 只解析 `<loc>`，不递归嵌套索引 | 多一跳，暂不做 |
| 5 | **V4 契约召回** | 0.33（B30 旧数），需"有契约且可达"的目标 | 目标不可达；另有发现召回代理指标（H27 §3.8） |

## 7. 值得记住的四个坑（都出在"同一份东西写了多处"）

| 批次 | 症状 | 根因 |
|---|---|---|
| B110 | `veripen discover` 运行即 NameError | 加了调用没加 import，E2E 绕过 CLI |
| B111 | 管道首行指令带 BOM | 切了 stdout 没切 stdin；且 utf-8 不吃 BOM |
| B112 | 结果页的链接全被吞 | 记录去重排在链接抽取之前 |
| B113 | `hunt` 少了 `--submit-forms` | 五个参数在三个入口各抄一遍 |

已收成单一来源的：面强度规则、短标识、severity 表、发现参数、oracle 强度。
