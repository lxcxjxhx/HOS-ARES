## 3. 测试分层

| 层 | 位置 | 内容 | 依赖 |
|---|---|---|---|
| L1 语义 | `tests/unit/test_ui_semantics.py`、`tests/unit/test_outcome*.py` | 纯逻辑（verdict 映射、四态） | 无 |
| L2 契约 | `tests/unit/test_ui_contract.py` | payload 键集、`?id`、版本 | 无 |
| L3 执行 | `tests/integration/test_sandbox_isolation.py`、`test_browser_render.py` | 容器/浏览器行为 | docker/Chromium（缺失则 SKIP 并记"未验"，不许记通过） |
| L4 平台 | `tests/unit/test_playbook*.py`、`test_blackboard_conflict.py`、`test_context_compress.py` | 资产与算法 | 无 |
| L5 结构 | `tests/unit/test_ui_dom.py` + `scripts/ui/*.py` | DOM 快照、静态 a11y、对比度 | 无浏览器 |

**L3 的诚实条款**：环境缺失时输出 `SKIP: <原因>`，账本 `dod` 记 `未验`（不是 ✅）。
这与 `make agent-discover` 的既有做法一致。

## 4. 快照与基线纪律

| 规则 | 内容 |
|---|---|
| 形态 | 纯文本大纲（缩进 + 标签 + 关键属性 + 文本），不是 PNG |
| 位置 | `web/static/__baselines__/<page>.txt`，单文件 ≤ 200KB |
| 更新条件 | 只有意图改变才更新；PR 贴 `-old/+new`（各 ≤ 20 行）并说明理由 |
| 归一化 | 去时间戳、属性排序、空白折叠 |
| 无法解释的差异 | 按回归处理，不许直接 `--update` |
