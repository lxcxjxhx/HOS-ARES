# H15 · 成片与一键演示（B70）

> **目标**：把两套已录好的素材（B65 控制台 10 页、B69 三幕终端）合成一支
> **能直接发给别人的成片**，并用一条 `make demo` 复现。

## 0. 为什么还要一支成片

B65 与 B69 各自是"证据"：一个证明界面能看，一个证明命令能跑。
但拿给别人看时，两段分散的文件等于"你自己去翻"。

成片要解决的是**叙事顺序**：先说这东西是什么（片头），再说能看什么（控制台），
最后说怎么干活（三幕终端）。章节卡让"哪一段是哪批的证据"仍然清楚。

## B70 · 成片与 `make demo`〔P1，0.5 人天〕

| 项 | 内容 |
|---|---|
| 目标 | `make demo` 一条命令：跑两支录制 → 插入片头与章节卡 → 合成 `out/demo/hos-ares-tour.mp4` |
| 判据 | A：成片 ≥40s、1280×720、H.264，ffprobe 可读；B：片头 + 3 张章节卡（概览 / 控制台 / 终端）都在画面里；C：两段素材的时长与成片时长满足 `成片 ≈ 片头 + 章节 + 素材之和`（误差 <1.5s）；D：`make demo` 在干净 clone 上可重跑出同样结构（场景/章节序列一致，不要求字节一致）；E：全程只连环回，不下载任何素材 |
| 产出 | `scripts/demo/build_tour.py` + `Makefile` 的 `demo` 目标 + `tests/unit/test_tour_build.py` |
| 依赖 | `scripts/demo/record_console.py`（B65）、`scripts/demo/record_terminal.py`（B69）、ffmpeg |
| PR | `b70/build-tour` |
| 回滚 | 删除脚本与 `make demo`；两段素材与既有产物不受影响 |

### 章节结构

| # | 卡片 | 时长 | 内容 |
|---|---|---|---|
| 1 | 片头 | 2.5s | 项目名 + 三支柱一句话 |
| 2 | 章节 · 控制台 | 1.5s | "10 个只读页，未验证不冒充高危" |
| 3 | 素材 | 27.4s | `console-tour.mp4`（B65） |
| 4 | 章节 · 三幕终端 | 1.5s | "run / agent / platform 真跑过程" |
| 5 | 素材 | 15.1s | `terminal-tour.mp4`（B69） |
| 6 | 片尾 | 2.5s | 复现命令 + 证据位置 |

合计约 **50s**。

### 实现方式

- 卡片用 HTML 渲染成 PNG（复用 B69 的终端风格，保持观感一致）；
- 卡片按 `duration` 进 concat 列表，素材直接以文件路径进同一列表；
- **不重编码素材**：两段都是 1280×720/30fps/yuv420p，可直接串；
  卡片也必须先转成同参数，否则 concat 会在接缝处出花屏。

### 与既有两批的关系

| 批 | 产物 | 角色 |
|---|---|---|
| B65 | `console-tour.mp4` | 素材（界面） |
| B69 | `terminal-tour.mp4` | 素材（能力） |
| B70 | `hos-ares-tour.mp4` | **成片**（给人看的） |

三段都保留：素材是可引用的证据，成片是可传播的叙事。

## 验收命令

```bash
make demo
ffprobe -v error -show_entries format=duration -of csv=p=0 out/demo/hos-ares-tour.mp4
python -m pytest tests/unit/test_tour_build.py -q
```
