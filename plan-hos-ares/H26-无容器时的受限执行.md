# H26 · 无容器时的受限执行（B84）

> 用户不提供 docker，要求"去搜集别的办法或者自行搞定"。
>
> 现实：这台 Windows 上 `docker` / `podman` / `nerdctl` 都没有，WSL 未安装，
> Docker Desktop 要管理员权限 + 重启。**装不上。**
>
> 但"没有容器"不等于"只能裸跑 subprocess"。Windows 有 Job Object。

## B84 · Windows Job Object 受限执行〔P1，1 人天〕

| 项 | 内容 |
|---|---|
| 目标 | 无容器运行时，用 Windows Job Object 提供**资源隔离 + 整组回收**；`isolation` 如实标 `job-object`，**不冒充容器** |
| 判据 | A：有 docker 时仍优先 docker（不改变既有行为）；B：无 docker 但有 Job Object 时走受限执行，`ExecResult`/doctor 明确标 `job-object`；C：进程数上限真生效（超限的子进程被拒）；D：超时/退出后**整组回收**，`terminate` 不留残余；E：`doctor` 的 sandbox 项区分 `docker` / `job-object` / `none` 三态 |
| 产出 | `veripen_core/sandbox/win_job.py` + `runner.select_executor` 三级选择 + `tests/unit/test_sandbox_job.py` |
| 依赖 | `sandbox/runner.py` 的 `Executor` 协议 |
| PR | `b84/job-object` |
| 回滚 | 删掉 win_job；`select_executor` 回到 docker-only |

### 它能保证什么，不能保证什么

| 保证 | 不保证 |
|---|---|
| 进程数上限（防 fork 炸弹） | 文件系统隔离（不隔离，同用户同盘） |
| 内存上限（防 OOM 拖垮宿主） | 网络隔离（不做） |
| 句柄关闭即整组杀（无残留） | 权限降级（不降） |
| 超时强杀（`TerminateJobObject`） | 内核隔离（不做） |

**这不是容器。** 它是"在同一个文件系统里跑，但跑不死宿主、也留不下进程"。

所以 `isolation` 必须如实写 `job-object`，报告与 doctor 都不许把它当成
`docker` 的同义词——那会让 E1 的"真隔离未验"变成假绿。

### 与 E1 的关系

E1 的判据是"容器内写 `/tmp` 宿主不可见"。**Job Object 给不了这个**：
它不建命名空间，写 `/tmp` 就是写宿主 `/tmp`。

所以 B84 **不翻绿 E1**。它做的是另一件事：把"裸跑"升级成"受限跑"，
并让 doctor 能如实报出当前是哪一档。

E1 仍挂着，卡点不变：需要真的容器运行时。

### 三级选择

```
docker/podman 有  → DockerRunner（isolation: container）
无 docker，Windows → WinJobRunner（isolation: job-object）
都没有           → None（调用方翻 BLOCKED）
```

**不许降级到裸跑**：没有隔离时宁可不执行，也不假装执行过。

## 执行记录（2026-11-05）

实测（本机无 docker/podman/WSL）：

```
$ python -m veripen_cli doctor --only sandbox
✅ 沙箱执行体 —— job-object（isolation: job-object —— 资源隔离，非容器；E1 真隔离仍未验）

$ select_executor().run(['python','-c','print(42)'])
outcome=ok exit=0 isolation=job-object out=42
```

判据 A–E 全绿：`test_sandbox_job.py` 6 passed，含
**进程数上限真生效**（上限 4 起 8 个被拒）与
**超时整组杀无残留**（tasklist 里查不到 marker）。

期间修的两处：
1. `AssignProcessToJobObject` 的权限写成了 `SET_INFORMATION|QUERY_INFORMATION`（错），
   正确的是 `SET_QUOTA|TERMINATE`；拿不到句柄时改为**如实报 `assign_failed`**，
   而不是当成功——"没进 job 就别假装受限"。
2. doctor 原来只显示类名，改为显示档位（`docker` / `job-object`）+ 一句
   "E1 真隔离仍未验"。

**E1 没有被翻绿**：Job Object 不建命名空间，写 `/tmp` 就是写宿主 `/tmp`。
本批做的是把"裸跑"升级成"受限跑"，并让 doctor 能如实报当前是哪一档。
