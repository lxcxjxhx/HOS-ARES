# 门面门槛评估（B43 产出，2026-11-03）

> **这是决策文档，不是开发文档。** 结论可能是"不做"，而"不做"同样是交付物（`H09 §2`）。
> 触发问题：控制台这一面，值不值得继续投到"产品门面"（对外演示 / 售前 / 客户自助）。

---

## 1. 三项判据（每项都必须能红，否则记"未评估"）

| # | 能力 | 最小可演示判据（能红） | 成本 | 风险 | 现状证据 |
|---|---|---|---|---|---|
| **1** | **写类动作**（`impact_ceiling` 放开到 write） | ① 单资产 ≤ N 请求且可逆（能列出补偿动作）② 每条写动作有审批记录 ③ 越界即零请求（缩 scope 演练）④ 写动作**不产生 verdict**（`act.*` 类型上拿不到） | 6–8 人天（含审批、回滚、审计） | 高：不可复现动作进入证据链；一旦失控，"报告可复现"这条招牌先倒 | 无：`impact_ceiling=READ_ONLY`，`H02 §2` 只有只读执行体 |
| **2** | **浏览器渲染** | ① 同输入两次 DOM 大纲 sha256 相同 ② 超时 → `BLOCKED(render_timeout)` ③ 每动作新 context（无 cookie 复用）④ 离线包可按 profile 不带 Chromium | 4 人天（B46） | 中：包体积 +300MB；渲染抖动会污染断言 | 无：全仓无 playwright |
| **3** | **容器隔离** | ① 容器内写文件宿主不可见 ② 任务后无残留容器 ③ 无运行时 → `BLOCKED` 且零请求 ④ 未绑定 host 被拒并记 `bounds` | 3 人天（B45） | 中：本机无 docker，可能整批记"未验" | 无：只有 `subprocess` |

**写不出判据的项**：无（三项都写出了）。所以本评估有效，不是"未评估"。

---

## 2. 结论

**停止**（界面定格为"内部审查面"）。

理由（按权重）：

1. **门面三要素全在执行面**：写类 / 浏览器 / 容器一项未做（`H01 §2` 的 E1/E2 是结构性缺失）。
   界面再漂亮，点进去仍只有"我验过什么"，没有"我能做什么"——这正是上一轮"不是集三家优点"的那条判断。
2. **对外承诺档位是 Harness（`D-H-07`）**，不是"产品级门面"；把控制台推到门面位置会顺手把承诺抬高，
   而 SLA / 运维 / 多租户都不在范围内（`H00 §5`）。
3. **投入产出比**：W1 已把"看得懂、敢签字"这一层做完（B35–B42，8 批 / 8 人天）。
   再加门面化（品牌、导航、多租户视图、导出、演示数据）≈ 15–20 人天，且 **必须**在执行面之后。
