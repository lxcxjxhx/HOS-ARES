# 控制台可访问性人工清单（B42）

> 静态闸门（`python scripts/ui/a11y_check.py`）只能保证**骨架与属性**存在；
> 焦点顺序、朗读行为、打印渲染、缩放与主题切换必须人工验。
> **PR 里必须写明：这次验了哪几项、没验哪几项**（D3：没验过的数不许出现）。

## 十二项

| # | 项目 | 怎么验（可照做） | 期望 |
|---|---|---|---|
| 1 | 跳过导航 | 打开页面，按第一下 `Tab` | 出现「跳到主内容」，`Enter` 后焦点进入主区 |
| 2 | 导航键盘可达 | `Tab` 穿过 9 个页签 | 每项都可聚焦；当前页有选中样式 |
| 3 | 表格行可聚焦 | `#/findings` 下按 `j` / `k` 或 `Tab` | 焦点环可见，移动不跳位 |
| 4 | 行内打开/返回 | 聚焦一行按 `Enter`，再按 `Esc` | 进详情页；`Esc` 回列表 |
| 5 | 搜索快捷键 | 按 `/` | 焦点进搜索框；`Esc` 只失焦不回列表 |
| 6 | 标题层级 | 详情页 / 未验证页 | 段标题是 `h2`，页面无跳级 |
| 7 | 未验证分组朗读 | 用屏幕阅读器读未验证页 | 四组标题与条数都能读出（**需读屏**） |
| 8 | 错误态朗读 | 断网或让接口 500 | `role=alert` 内容被读出，且文案不说「没有发现」 |
| 9 | 空态朗读 | 搜索到一个不存在的词 | `role=status` 内容被读出 |
| 10 | 打印 | 浏览器打印预览 | 无导航/工具条；表格不截断；结论徽标保留 |
| 11 | 200% 缩放 | 浏览器缩放 200% | 卡片与表格不重叠、不横向溢出 |
| 12 | 深色主题 | 系统切深色后重开 | 正文/次要文字对比度仍可读 |

## 静态闸门能覆盖的（不用人验）

| 项 | 检查 |
|---|---|
| 地标 | `<main id="main">`、`<nav aria-label>`、`<html lang>` |
| 动态播报 | `aria-live`、空态 `role=status`、错误 `role=alert` |
| 可访问名称 | 表单控件必须有 `aria-label`/`<label>` |
| 焦点可见 | `:focus-visible` + `--focus` 令牌（对比度进 `contrast_check`） |
| 顺序 | 禁止正 `tabindex` |
| CSP | 禁止内联 `on*=` 事件 |
| 动效/打印 | `prefers-reduced-motion`、`@media print` 必须存在 |
