# 现场口述（三句话）+ 5 分钟演示脚本

## 三句话

**这是什么**：一个把"我发现一个洞"变成"这是证据，你现在自己复现一遍"的验证器。

**它不做什么**：不猜路径、不替你做判断、不碰授权范围外的任何东西；判不了就写判不了。

**越界会怎样**：越界不是"尽力而为"，是断连 + 记事故；缩 scope 后它会拒绝执行且一个包都不发。

## 5 分钟脚本（逐句可照读）

| 时间 | 命令 | 说什么 |
|---|---|---|
| 0:00 | `make up` | "先起环境：数据库、worker、靶场。" |
| 0:30 | `make demo` | "提交任务：一个客户档、一个资产、九类验证器。注意它在按 oracle 顺序跑。" |
| 1:30 | 看 `out/demo/report.md` | "三条发现，每条都有 capsule id、置信度、复现命令。" |
| 2:10 | （demo 内）replay | "把 agent 关掉，只用证据包复现。它重发了 baseline / probe / control。" |
| 2:50 | （demo 内）缩 scope | "把资产移出 scope。它拒绝执行，而且**一个包都没发**。" |
| 3:30 | `make bench` | "44 例三轮，误报 0，越界 0，三轮判定完全一致——因为判定是纯函数。" |
| 4:10 | `make demo-alt` | "同一份镜像，只换了客户档 YAML。" |
| 4:40 | — | "能卖第二家、差异没漏进代码、内网能装、每条发现能复现、有数。" |

**演示纪律**：先给命令再给一句话解释，不念代码；任一步失败直接切下一条；
第 2:50 的「拒绝执行」是全场最重要的一步，**不要因为怕失败跳过**。
