## 1. 三包分层与依赖方向

```
            ┌─────────────────────────────────────────┐
            │            veripen_cli                  │  run/replay/bench/doctor/package/report
            └───────┬──────────────────────┬──────────┘
                    │                      │
            ┌───────▼────────┐    ┌────────▼─────────┐
            │ veripen_oracles│───▶│  veripen_core    │
            │ 4 个验证器插件  │    │ 调度/agent/guard │
            └────────────────┘    │ 证据模型/接口    │
                    ▲             └────────┬─────────┘
                    │                      │ 读
            ┌───────┴──────────────────────▼─────────┐
            │   profiles/<name>/*.yaml  (纯数据)      │
            └────────────────────────────────────────┘
```

**依赖铁律**

1. `core` 不 import `oracles`，只依赖抽象 `Oracle` 协议（依赖倒置）。
2. `core` 与 `oracles` 都**不得**出现客户标识（域名、公司名、车型、接口路径）。`make lint-noleak` 强制。
3. `profiles` 是纯数据，不允许包含可执行代码（无 Jinja 逻辑之外的东西；建议连 Jinja 都不用）。
4. 唯一出口是 `cli`，库层不 `print`、不读环境外状态。

## 3. 内核接口契约（签名冻结）

### 3.1 Oracle 协议

```python
class ImpactClass(str, Enum):
    READ_ONLY = "read_only"
    REVERSIBLE_WRITE = "reversible_write"   # 本期不启用

class Verdict(str, Enum):
    VERIFIED = "VERIFIED"
    REFUTED = "REFUTED"
    INCONCLUSIVE = "INCONCLUSIVE"
    BLOCKED = "BLOCKED"

@dataclass(frozen=True)
class RequestPair:
    variant: str                 # 变体名，如 "bool_true"/"bool_false"/"control"
    baseline: HttpTrace          # 基线请求的完整可复现记录
    probe: HttpTrace             # 变体请求的完整可复现记录

class Oracle(Protocol):
    id: str                      # "sqli_bool_diff"
    version: str                 # "1.0.0"，进 capsule
    cwe: str                     # "CWE-89"
    impact: ImpactClass
    requires: list[str]          # 例 ["auth:secondary"]，不满足则 BLOCKED
    params_schema: type[BaseModel]

    def applicable(self, ctx: TargetContext) -> bool: ...
    def plan(self, ctx: TargetContext, baseline: HttpTrace) -> list[Variant]: ...
    # 关键：judge 是纯函数，无 IO、无时钟、无随机
    def judge(self, pairs: list[RequestPair]) -> Judgement: ...

@dataclass(frozen=True)
class Judgement:
    verdict: Verdict
    reason: str                  # 机器可读码 + 人读短句
    assertion: dict              # {"kind":"differential","expected":...,"observed":...}
    confidence: float            # 0..1，规则算出，不让模型给
```

**这条设计是整个项目的技术核心**：

> **判定是纯函数，网络是外围。**
> 所以 oracle 可以 100% 单测、可以离线回放、可以三次跑分完全一致、可以把"模型不确定性"彻底挡在判定之外。

### 3.2 三个可变点，其余全冻结

| 可变点 | 扩展方式 | 是否改内核 |
|---|---|---|
| 客户差异 | 新增 `profiles/<name>/` | ❌ |
| 漏洞类别 | 新增 `veripen_oracles/<id>/` 并注册 | ❌ |
| 报告规范 | `report.frameworks[]` + 模板片段 | ❌ |

除此之外任何"想加个 if"的冲动，进二期池。

### 3.3 TargetContext（传给 oracle 的唯一上下文）

```python
@dataclass(frozen=True)
class TargetContext:
    asset: Asset                 # id/kind/value/criticality/tags
    base_url: str
    auth: dict[str, AuthHandle]  # role -> 句柄（不暴露明文，取用时解密）
    params: BaseModel            # oracle 自己的参数（来自 profile）
    clock_t0: int                # 统一时钟（UTC 秒）
    oob: OobChannel | None       # 本地回调通道（ssrf 用）
```

## 4. 模块职责表（谁做什么，谁不许做什么）

| 模块 | 做 | **不做** |
|---|---|---|
| `scheduler` | 扫描过期租约、重排、判死信 | 不执行任务、不发请求 |
| `lease` | 领/续/释放，全部 Redis 原子操作 | 不管业务状态 |
| `guard.scope` | 三处校验，失败即抛 `ScopeDenied` | 不重试、不降级、不"尽力而为" |
| `guard.ratelimit` | 令牌桶排队，记录等待时长 | 不静默丢弃 |
| `tools.http` | 发请求、归一化响应、4KB 截断、错误分类 | 不做判定、不猜语义 |
| `oracles.*` | 构造变体、纯函数判定、产出 assertion | 不发请求（请求由 tools 发） |
| `evidence` | 组 capsule、算哈希、脱敏、seal | 不改判定结果 |
| `report` | 三视图渲染 | 不引入报告里没有的证据 |
| `agent` | 决定"下一步调哪个 oracle/工具" | **不参与判定** |

最后一行是纪律：agent 永远拿不到写 finding 的权力，只能 `record_finding(oracle_id, verdict_ref)`，而 verdict 来自纯函数。

## 5. 关键数据流（一次任务的完整链路）

```
1  POST /tasks {profile, asset_ids, oracle_ids}
     └─ idem_key = sha256(engagement|asset|oracle|params_canonical)
        └─ 冲突 → 直接返回已有 task_id（不重复打目标）
2  worker 心跳续租 → 原子领取 QUEUED 任务 → LEASED → RUNNING
3  guard.plan：scope/deny/enabled/impact 四查（不通过 → BLOCKED finding）
4  agent 循环：
     observe(assets 探测结果) → 选 oracle → guard.preflight → 令牌桶
       → tools.http 发基线请求 → oracle.plan 变体
       → tools.http 发变体（每组前后各一次对照）→ oracle.judge（纯函数）
       → evidence.seal(capsule) → record_finding
5  guard.post_connect：每次连接后按解析 IP 复核，越界即断连 + 记事件
6  预算耗尽或收敛 → DONE；证据缺失的 finding 降级为 UNVERIFIABLE 不入报告
7  report 渲染 MD/SARIF/JSON，每条带 capsule 路径与 self_sha256
```

## 6. 缓存与幂等边界

| 对象 | 幂等键 | 说明 |
|---|---|---|
| task | `sha256(engagement|asset|oracle|params_canonical)` | 唯一索引，重复提交返回同一结果 |
| oracle run | `sha256(task_id|oracle_id|oracle_version|asset_id)` | 同一任务同一 oracle 重跑复用 capsule |
| capsule | `self_sha256`（规范化 JSON） | 内容寻址，二次生成字节相同 |
| 报告渲染 | `sha256(sorted(finding_ids)|template_ver)` | 同输入同输出 |
