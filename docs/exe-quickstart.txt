HOS-ARES 快速开始
=================

一、这个程序是什么
    一个**只读**的可验证渗透验证控制台：覆盖、发现、未验证、路由、审计、审批、边界。
    它不改目标、不发请求、不写你的产物目录；唯一的写入是"审批决定"（需 --db）。

二、怎么打开
    双击桌面或开始菜单里的 HOS-ARES：
      1) 程序起一个本地只读服务（默认向系统要一个空闲端口）；
      2) 自动用默认浏览器打开界面；
      3) 控制台窗口里会打印地址与"数据：…"这一行。
    关掉控制台窗口或按 Ctrl+C 即结束。

三、界面里为什么是空的
    控制台读的是**运行产物**，不自己造数据。想有内容，先跑一次：

      veripen run    --target <URL> --openapi <spec>  --out out/run
      veripen hunt   --target <URL> --openapi <spec>  --out out/hunt

    然后：
      HOS-ARES.exe --record out/hunt.json
    或把产物放到 out\hunt.json（默认会去找它）。

四、常用参数
      --record <path>   指定产物（hunt.json 或 findings.json）
      --port <n>        固定端口（默认自动挑空闲端口）
      --no-browser      不自动打开浏览器（脚本里用）

五、卸载
    Windows 设置 → 应用 → HOS-ARES → 卸载；
    或开始菜单 → 卸载 HOS-ARES。

六、它不会做什么（写在这里是为了不让读者误解）
    * 不替你判"有没有漏洞"：结论只认证据链（capsule + 哈希）；
    * 不在界面上"编辑/删除"发现：那是报告与账本的事；
    * 不给命令执行入口：界面没有"跑一条命令"的按钮，也没有地址输入框。

注意：静默安装（/VERYSILENT）**不会**自动打开界面——企业批量部署时这是预期的；
装完从开始菜单（或桌面快捷方式，若安装时勾了）点开即可。
